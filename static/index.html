Architecture & Optimization

1. Preprocessing

Satellite imagery undergoes data augmentation (random flips and rotations) during training to increase robustness. We also normalize the images using ImageNet statistics to ensure numerical stability and faster convergence.

2. Visual Descriptors & Architecture

Instead of manual descriptors (like HOG or SIFT), this model utilizes a Convolutional Neural Network (CNN). The CNN consists of 4 convolutional blocks with increasing filter sizes (32 -> 64 -> 128 -> 256), followed by Batch Normalization to prevent internal covariate shift. This enables the model to automatically learn hierarchical visual features tailored for ship detection.

3. Hyperparameters & Cross-Validation

We train using the Adam optimizer with a learning rate of 0.001 and BCEWithLogitsLoss. To ensure generalizability and avoid overfitting, we perform a 5-fold Cross-Validation across the training set before isolating the best model weights for this final blind evaluation.
